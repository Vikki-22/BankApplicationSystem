# Bank Application System 🏦

A simple and efficient **Bank Management System** developed using **Java, JDBC, and MySQL**.  
This project allows users to perform banking operations like creating accounts, depositing money, withdrawing money, transferring funds, changing PINs, and viewing account details through a console-based interface.

---

## ✨ Features

- Add & Delete Account  
- Deposit & Withdraw Money  
- Transfer Amount  
- Change Account PIN  
- View Single & All Account Details  
- JDBC + MySQL Database Connectivity  

---

## 🛠️ Tech Used

- Core Java  
- JDBC  
- MySQL  
- Eclipse IDE  

---

## 📌 Concepts Covered

- OOPs  
- DAO Design Pattern  
- Exception Handling  
- Transaction Management  
- Collections Framework  

---

## 🚀 Run Project

1. Configure MySQL Database  
2. Add MySQL JDBC Driver  
3. Run `Controller.java`
